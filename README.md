Task Management Application

A full-stack Task Management Application developed using the MERN Stack (MongoDB, Express.js, React.js, and Node.js). This application allows users to manage projects and tasks efficiently with secure authentication and an organized dashboard.

Features

- User Registration and Login
- JWT-Based Authentication
- Secure Password Management
- Dashboard Overview
- Create and Manage Projects
- Create, Update and Delete Tasks
- View Project Details
- User Management
- Task Management
- RESTful API Integration
- MongoDB Database Integration

Tech Stack

Frontend

- React.js
- JavaScript
- HTML5
- CSS3
- Axios
- React Router
- Vite

Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- bcrypt.js


Installation and Setup

1. Clone the Repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the Project

cd project-task-manager

3. Backend Setup

cd backend
npm install
npm run dev

4. Frontend Setup

Open another terminal:

cd frontend
npm install
npm run dev

Application Workflow

1. Register a new account.
2. Log in with your credentials.
3. Access the dashboard.
4. Create and manage projects.
5. Add tasks to projects.
6. Update task information and status.
7. Manage users and project activities.
8. Log out securely.
